# Plataforma de Análise de Dados Geográfica e Econômica

## Como Usar

### 1. Instalar Dependências
Duplo-clique em: `instalar_dependencias.bat`

### 2. Iniciar o Servidor
Duplo-clique em: `iniciar.bat`

Você verá:
```
=====================================
  ✅ Plataforma Pronta!
=====================================

📱 Acesse em: http://localhost:5000
```

### 3. Abrir no Navegador
Duplo-clique em: `abrir_plataforma.bat`

Ou abra manualmente: http://localhost:5000

## Funcionalidades

✅ **Upload de Dados** - CSV ou Excel
✅ **Análise Estatística** - Média, Mediana, Desvio Padrão
✅ **Matriz de Correlação** - Entre variáveis
✅ **Distribuição** - Histogramas
✅ **Agrupamento** - Dados por categoria
✅ **Dashboard Interativo** - Gráficos em tempo real

## Dados de Teste

Use o arquivo `exemplo_dados.csv` para testar!

Contém dados geográficos, econômicos e sociais de 30 municípios de Santa Catarina.
